Fix an endless loop in the cleanup of expired Actions logs. Tasks without a log file — such as the placeholder task created for the outer job of a reusable workflow call — were skipped without being marked as expired, so the same tasks were selected again on every iteration. On instances where 100 or more such tasks were older than `[actions].LOG_RETENTION_DAYS`, the cleanup never finished and queried the database continuously, which could make Actions unresponsive. Instances that already accumulated such tasks need to run `UPDATE action_task SET log_expired = true WHERE log_expired = false AND (log_filename IS NULL OR length(log_filename) = 0);` once to clear the backlog.
