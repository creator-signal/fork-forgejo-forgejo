This adds a branch protection option that when selected, will block merging if a file is affected by a rule in ```CODEOWNERS``` unless one of the owners listed in that rule has approved. If the only owner is the pr author, then that rule is skipped as you cannot approve your own pull request.

#### For example:
A repo has the following ```CODEOWNERS``` file
```
bobsfile.txt @bob
alicesfile.txt @alice
bobandalicesfile.txt @bob @alice
```
If Bob submits a pr that edits ```alicesfile.txt```, merging will be blocked until Alice approves that request, regardless of any other approvals. If Bob submits a change to ```bobsfile.txt```, then since there isn't another owner to approve changes to that file, then alice could approve it. Bob making the request as the only owner is implicit permission. However, if Bob submits a request editing ```bobandalicesfile.txt``` then it will be blocked until it's approved by Alice.
