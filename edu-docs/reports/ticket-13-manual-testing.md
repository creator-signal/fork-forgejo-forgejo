# Отчет по задаче №13: Ручное тестирование и багфикс

## Что сделано в процессе проверки

1. **Авторизация**: Поправил `InstructorSubmissions`. Раньше там была "магическая цифра" 0 для проверки прав, заменил её на правильную константу `unit_model.TypeCode(1)`.
2. **Данные пользователей**: 
    - Столкнулся с тем, что в таблице решений были только ID студентов. 
    - Добавил подгрузку имен пользователей в обработчик и сделал мапу `UserMap`. 
    - В шаблоне `instructor_submissions.tmpl` теперь выводится имя студента, а не просто цифры.
3. **Компиляция**: Ещё раз проверил, что всё собирается командой `go build` для `routers/web/edu`.

## Результат
Основные баги поправлены, интерфейс стал более человечным за счёт отображения имен. Инструкция по тестированию лежит в `docs/manual_testing_guide.md`.
