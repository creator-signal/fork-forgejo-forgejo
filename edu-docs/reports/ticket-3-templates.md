# Отчет по задаче №3: Макеты интерфейсов

## Что сделано
1. **Структура директорий**:
   - Создана папка `templates/edu` для шаблонов образовательного модуля.

2. **Шаблоны**:
   - `list.tmpl`: Страница списка доступных заданий. Отображает карточки с названием, дедлайном и кнопкой перехода.
   - `details.tmpl`: Страница просмотра задания. Показывает описание, текущий статус решения студента и результаты тестов.
   
3. **Стиль**:
   - Использованы стандартные классы Fomantic UI (Semantic UI), совместимые с темой Forgejo (классы `ui container`, `ui segment`, `ui card` и т.д.).
   - Шаблоны наследуют базовый лейаут (`template "base/head"` и `footer`).

## Как верифицировать
- Проверить наличие файлов `.tmpl` в `templates/edu/`.
- Визуальная проверка будет доступна после реализации контроллеров (Тикет-8 и далее), которые будут рендерить эти шаблоны.
