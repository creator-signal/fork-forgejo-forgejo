# Отчет по задаче №10: Панель преподавателя

## Что сделано

### 1. Доступ к данным
- Обновил интерфейс `Repository`: добавил метод `GetSubmissions(ctx, assignmentID)`.
- Реализовал его через `squirrel`, чтобы доставать все решения по конкретному заданию. Поля структуры корректно связал с колонками в БД.

### 2. Слой сервиса
- В `EducationalService` прокинул метод для получения списка решений.

### 3. Веб-обработчик (`routers/web/edu/instructor.go`)
- Реализовал `InstructorSubmissions`.
- Добавил **проверку прав**: доступ к списку решений есть только у тех, у кого есть права админа или записи в репозитории-шаблоне. Так мы ограничили доступ студентов к чужим работам.
- Рендерит шаблон со списком всех сданных работ.

### 4. Шаблон (`templates/edu/instructor_submissions.tmpl`)
- Сверстал таблицу со списком решений студентов. 
- Пока отображается ID студента, статус, ссылка на репозиторий и время последнего обновления.

## Исправления
- Поправил ошибки компиляции, где имена полей в структурах не совпадали с тем, что возвращал SQL.
- Разобрался с импортами Forgejo для проверки прав доступа.

## Результат
Интерфейс для преподавателя готов. Перехожу к стабилизации и написанию тестов.
