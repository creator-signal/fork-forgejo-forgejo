# Руководство по ручному тестированию (Manual Testing Guide)

Этот документ описывает шаги для проверки функциональности образовательного расширения Forgejo.

## Подготовка
1.  Запустите Forgejo: `go run main.go web`.
2.  Убедитесь, что у вас есть два пользователя:
    -   `instructor` (Преподаватель)
    -   `student` (Студент)

## Сценарии

### 1. Создание задания (Instructor)
1.  Войдите как `instructor`.
2.  Создайте новый репозиторий (например, `homework-1-template`).
3.  (Опционально) Добавьте файлы задания (README.md, тесты).
4.  Этот шаг пока выполняется через БД или API, так как UI создания задания в Ticket-5 был реализован только на уровне сервиса, но админка может не иметь кнопки.
    -   *Workaround:* Используйте SQL для вставки задания, ссылающегося на этот репозиторий:
        ```sql
        INSERT INTO edu_assignments (repo_id, title, description, deadline_unix, created_unix, updated_unix)
        VALUES ((SELECT id FROM repository WHERE name='homework-1-template'), 'Homework 1', 'Solve tasks', 1700000000, 1600000000, 1600000000);
        ```

### 2. Просмотр списка заданий (Student)
1.  Войдите как `student`.
2.  Перейдите по адресу `/edu/assignments`.
3.  **Ожидаемый результат:**
    -   Вы видите список заданий.
    -   Задание "Homework 1" присутствует.
    -   Статус: "Not Started" (или аналогичный).

### 3. Начало выполнения задания (Student)
1.  Нажмите на задание "Homework 1".
2.  На странице деталей нажмите кнопку "Start Assignment" (или "Join").
3.  **Ожидаемый результат:**
    -   Вы перенаправлены на страницу задания.
    -   Появилась ссылка на **Ваш репозиторий** (форк).
    -   В базе данных (`edu_submissions`) появилась запись.
    -   В списке репозиториев студента появился `homework-1-template-student`.

### 4. Просмотр работ студентов (Instructor)
1.  Войдите как `instructor` (владелец `homework-1-template`).
2.  Перейдите по адресу `/edu/assignments/{id}/submissions` (ID можно взять из URL списка).
3.  **Ожидаемый результат:**
    -   Вы видите таблицу.
    -   В таблице есть запись студента `student`.
    -   Статус "Started".
    -   Есть ссылка на репозиторий студента.

## Проверка CI/CD (Если настроен Runner)
1.  В репозитории студента запушьте изменение.
2.  Если Action настроен, он должен пройти.
3.  Проверьте, обновился ли статус в `edu_submissions` (если статус в Action был `success`).

## Ограничения
- Отсутствует UI для создания задания (требует SQL или API вызов).
- Нет автоматического обновления статуса в реальном времени (требует перезагрузки страницы).
